# Recovery drill record

Copy this template to `YYYY-MM-DD.md` for every restore drill. Do not include
credentials, customer PII, or backup contents.

```md
# Restore drill YYYY-MM-DD
- Incident commander:
- Data owner:
- Tenant fixture (non-sensitive identifier):
- Backup ID / completed_at:
- Drill start / verified_at:
- RPO measured / target: / 24h
- RTO measured / target: / 60m
- Artifact, gzip, SQL, migration checks:
- Sentinel sale / fiscal document / stock / cash validation:
- Smoke command and result:
- Remediation owner and due date:
```
